# Лабораторная работа №8

Вариант 12 — редактор учебного расписания. Занятия хранятся в SQLite, их можно добавлять, изменять, удалять и фильтровать по дню недели. Сервер проверяет время и не разрешает пересекающиеся занятия.

## Запуск

```bash
npm install
npm start
```

После запуска приложение доступно по адресу `http://localhost:3000`.

## API

- `GET /api/lessons` — все занятия;
- `GET /api/lessons?day=2` — занятия за выбранный день;
- `GET /api/lessons/:id` — одно занятие;
- `POST /api/lessons` — добавить занятие;
- `PUT /api/lessons/:id` — изменить занятие;
- `DELETE /api/lessons/:id` — удалить занятие.

Пример тела запроса:

```json
{
  "title": "Веб-технологии",
  "day": 2,
  "start_time": "10:00",
  "end_time": "11:30",
  "cabinet": "312",
  "color": "#3768b5"
}
```
