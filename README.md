# Лабораторная работа №8

Вариант 12 — редактор учебного расписания. Бэкенд написан на C# и ASP.NET Core (.NET 10), данные хранятся в SQLite через Microsoft.Data.Sqlite. Занятия можно добавлять, изменять, удалять и фильтровать по дню недели. Сервер проверяет время и не разрешает пересекающиеся занятия. Цвет карточки назначается автоматически по названию предмета в существующем фронтенде.

## Запуск

Нужен .NET SDK 10. Команды выполняются из каталога лабораторной:

```powershell
dotnet run --project Lab8.csproj
```

После запуска приложение доступно по адресу `http://localhost:3000`.

При первой сборке NuGet загрузит зависимость SQLite. Node.js не требуется. База создаётся автоматически в `data/schedule.db`; существующая база сохраняется и совместима с прежней схемой. Проверка пересечений и запись выполняются в одной транзакции, включая одновременные запросы.

Другой адрес можно указать через `dotnet run --project Lab8.csproj -- --urls http://localhost:3008`, переменную `ASPNETCORE_URLS` или `PORT`. Для другого файла базы задайте `DATABASE_PATH` (например, `$env:DATABASE_PATH = 'C:\data\schedule.db'`).

## API

Таблица `schedule`: `id`, `subject`, `teacher`, `room`, `day`, `start_time`, `end_time`.

- `GET /api/schedule` — все занятия;
- `GET /api/schedule?day=2` — занятия за выбранный день;
- `GET /api/schedule/:id` — одно занятие;
- `POST /api/schedule` — добавить занятие;
- `PUT /api/schedule/:id` — изменить занятие;
- `DELETE /api/schedule/:id` — удалить занятие.

Пример тела запроса:

```json
{
  "subject": "Веб-технологии",
  "teacher": "Иванов И. И.",
  "room": "312",
  "day": 2,
  "start_time": "10:00",
  "end_time": "11:30"
}
```

## Проверка

```powershell
dotnet run --project tests/Lab8.Tests.csproj
```

Проверки запускают настоящий сервер на свободном порту с временной SQLite-базой: схема, CRUD, фильтрация, ошибки полей, границы времени, пересечения и соседние занятия, параллельные запросы, сохранение данных после перезапуска и раздача фронтенда. Рабочая база не изменяется.

## Публикация

```powershell
dotnet publish Lab8.csproj -c Release -o publish
dotnet .\publish\Lab8.dll
```

Каталог `public` включён в результат публикации. При запуске опубликованного приложения база по умолчанию находится рядом с ним, в `data/schedule.db`; `DATABASE_PATH` позволяет подключить существующую базу.
